Referência do produto

Ferramentas de dados
para servidores Lineage 2.

L2Toolkit reúne conversores, geradores e utilitários para transformar dados do cliente em artefatos prontos para o seu servidor.

.NET 10 Avalonia UI Windows 10/11 · x64
Fluxo principalCliente → servidor
Dados LiveProtocolo 166
SaídasGRP · XML · DAT

Primeiros passos

Instalação e configuração

Prepare o ambiente e os assets Classic antes de executar a aplicação.

Ambiente suportado

Windows 10 ou 11, arquitetura x64 e .NET 10.

Para desenvolver

Use Visual Studio ou Rider para restaurar, compilar e executar o projeto.

Assets Classic

Os recursos abaixo são necessários para as ferramentas que leem os dados Classic. Live Data usa os arquivos compactados embutidos no aplicativo.

ItemName_Classic-eu.txtNomes de itens
EtcItemgrp_Classic.txtItens diversos
Armorgrp_Classic.txtDados de armaduras
Weapongrp_Classic.txtDados de armas
Skillgrp_Classic.txtDados de skills
ItemStatData.txtNecessário para XML de equipamentos
  1. 01
    Posicione os assetsCopie os arquivos Classic para a pasta assets/.
  2. 02
    Inicie o L2ToolkitExecute pela IDE ou pelo binário compilado e selecione a ferramenta desejada.

Índice de ferramentas

O que cada módulo resolve

Acesse a ferramenta pelo resultado que você precisa gerar. Os módulos abaixo seguem o fluxo de dados comum do cliente para o servidor.

Gerar PortasConverte dados do UnrealEd em XML. Animações (Pawn Data)Gera dados de animação para NPCs. Gerenciador de SpawnCria arquivos de spawn organizados. Prime ShopGera itens e configurações da loja. Live Data (166)Processa dados Live e gera XML. Converter GeodataConverte geodata entre formatos binários. Pesquisar ÍconeBusca ícones pelo ID do item. Separar LogsAnalisa e segmenta logs do servidor. Corrigir DescriçãoProcessa descrições de itens. Upgrade EquipmentGerencia dados de upgrade.

Ferramenta avançada

Live Data (166)

Converta dados do cliente Live para uso no Classic. Os arquivos .l2dat vêm comprimidos e embutidos no executável, então não há etapa de preparação de arquivos Live.

Dados sob demanda

O pacote usa compressão Brotli: cerca de 190 MB de dados são distribuídos em aproximadamente 2,5 MB e mantidos em cache após a descompressão.

Dados disponíveis

Skillgrp.l2datDados de skills
SkillName-eu.l2datNomes das skills
ItemName-eu.l2datNomes dos itens
Weapongrp.l2datDados de armas
Armorgrp.l2datDados de armaduras
EtcItemgrp.l2datItens diversos
ItemStatData.l2datStats para a geração de XML
BrotliCompactação dos recursos

Tipos de processamento

Skills, Weapons, Armor e Items. Armas e armaduras também podem gerar XML.

Opções de conversão

Converta automaticamente S80, R95, R99 e R110 para grade S e habilite o brilho de enchant de armaduras.

Fluxo de uso

  1. 01
    Selecione o tipoEscolha Skills, Weapons, Armor ou Items.
  2. 02
    Informe os IDsUse um ID, vários IDs separados por ; ou um intervalo como 1000...1010.
  3. 03
    Ajuste as opçõesConfigure a conversão de grade e o efeito de enchant quando aplicável.
  4. 04
    Gere os dadosO resultado contém arquivos GRP, nomes localizados e XML de equipamentos quando disponível.

Ferramenta avançada

Converter Geodata

Converta geodata binária entre formatos usados por servidores Lineage 2. A extensão identifica o formato de entrada automaticamente.

Entradas aceitas

.l2j, _conv.dat, .l2d, .l2g, .l2s, .l2m, .rp e _path.txt.

Saídas disponíveis

Gere arquivos .l2j, _conv.dat ou .l2g.

Cópia sem conversão

Quando o formato de entrada já for o formato de saída, o arquivo é copiado diretamente para preservar os dados.

Conversão em quatro etapas

  1. 01
    Selecione a pasta de entradaO L2Toolkit identifica o formato pela extensão do arquivo.
  2. 02
    Selecione a pasta de saídaOs arquivos usam a nomenclatura padrão X_Y.ext.
  3. 03
    Escolha o formato de destinoSelecione L2J, CONV_DAT ou L2G.
  4. 04
    Inicie a conversãoAcompanhe o progresso e cancele a operação quando necessário.

Para contribuidores

Desenvolvimento

A base é uma aplicação Avalonia em C# com compilação Native AOT e módulos separados por responsabilidade de leitura, transformação e interface.

Stack

C# .NET 10, Avalonia UI 11.2, Native AOT e Visual Studio ou Rider.

Contribuições

Faça um fork, crie uma branch para a alteração, registre os commits e abra um Pull Request.

Estrutura do projeto

L2Toolkit/
├── src/              # Projeto do app (pasta = namespace L2Toolkit.*)
│   ├── Views/        # Janela principal e páginas (AXAML + code-behind)
│   ├── ClientDat/    # Leitura/escrita de client .dat e compressão .l2dat
│   ├── Models/       # Modelos de dados
│   ├── Parsing/      # Parsers de texto
│   ├── Processing/   # Transformação (game → XML), Geodata
│   ├── Settings/     # Persistência (AppDatabase)
│   ├── Utilities/    # Logs, Parser, MaterialType, TableManager
│   ├── Data/         # Dados embutidos (H5Names, Presets)
│   ├── Tables/       # Recursos .l2dat embutidos
│   └── Assets/       # Ícones
├── packaging/        # Inno Setup (Windows) e Info.plist (macOS)
├── scripts/          # build.ps1 usado pelo Makefile
└── docs/             # Documentação
