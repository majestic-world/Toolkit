## Agent skills

### Issue tracker

Issues e specs vivem em arquivos Markdown sob `.scratch/`. Veja `docs/agents/issue-tracker.md`.

### Triage labels

Usa os cinco labels padrão de triagem. Veja `docs/agents/triage-labels.md`.

### Domain docs

Layout single-context com `CONTEXT.md` e `docs/adr/`. Veja `docs/agents/domain.md`.

### L2Toolkit engineering

Antes de alterar UI Avalonia, textos de interface, processamento de dados, tabelas `.l2dat` ou client `.dat`, leia `docs/agents/l2toolkit-engineering.md`. Use os termos de `CONTEXT.md`.
